# Sutra — Scripts

- `configure-mcp-clients.ps1` — Safely adds or updates the `scio-revit` MCP server entry across installed AI clients (Claude Desktop, Claude Code, Antigravity, Gemini CLI, Cursor, Windsurf, VS Code, Codex CLI) without touching other servers.
- `install-cad.ps1` — Builds and installs the `Scio.Cad` AutoCAD / Civil 3D add-in.
- `tools/generate-installer-assets.py` — Generates installer icons and wizard banners into `build/assets/`.
